# Fuel Salt Pump — Detailed Specifications

**Reference:** ORNL-TM-517; ORNL-TM-728, Section 3.5

---

## 1. Hydraulic Performance

| Parameter | Value |
|-----------|-------|
| Fluid | LiF-BeF₂-ZrF₄-UF₄ at 640 °C |
| Density | 2.24 g/cm³ (2,240 kg/m³) |
| Viscosity | ~9 cP (9 × 10⁻³ Pa·s) |
| Flow rate | 75.7 L/s (1,200 USgpm) |
| Total developed head | 18.3 m (60 ft) |

| NPSH required | <1.5 m (5 ft) |
| Specific speed (Ns) | ~2,100 (US units: rpm × √gpm / H^0.75) |
| Pump efficiency | ~55% |
| Shaft power | ~56 kW (75 hp) |

## 5. Shaft Seal (Labyrinth + Face Seal)

| Parameter | Value |
|-----------|-------|
| Type | Labyrinth (non-contact) + face seal |
| Face seal materials | Carbon graphite (rotating) vs. Hastelloy-N (stationary) |
| Face seal spring load | ~15 N (controlled to prevent excessive face wear) |
| Face seal leakage | <0.01 L/min He at operating conditions |
| He purge flow (into seal from above) | 1.0 L/min minimum |
| He pressure (above seal) | 3–5 kPa above pump bowl gas-space pressure |
| Seal replacement | Can be replaced with cover plate removal (remote tooling) |

## 9. Acceptance Tests

| Test | Acceptance Criteria |
|------|-------------------|
| Hydraulic performance (water test) | Flow rate ≥ 1,200 gpm at ≥ 60 ft head at 1,750 rpm |
| Shaft vibration (ambient) | ≤2.5 mm/s RMS at bearing housing (ISO 10816) |
| Shaft runout | ≤0.05 mm TIR at impeller |
| Seal leakage (He purge, ambient) | ≤0.01 L/min He leakage to bowl side |
| Motor no-load current | Within 10% of rated no-load current |
| High-temperature run (if hot test rig available) | 8 h at 650 °C, full flow; post-test inspection of impeller/seal |
